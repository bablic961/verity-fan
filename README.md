# ВЕРИТИ.fan

Мобильный фан-сайт про мем «Верити» — жёлтый смайлик из хоррор-сериала ThatMob по Minecraft, захвативший соцсети в 2026 году.

## Быстрый запуск

Нужен только Node.js 18+ (зависимостей нет).

```bash
node server.js
```

Или:

```bash
npm start
```

Сервер поднимется на `http://localhost:3000`.

## Открыть с телефона

Телефон и компьютер должны быть в одной Wi-Fi-сети. При запуске сервер печатает адрес вида:

```
С телефона (Wi-Fi):  http://192.168.1.42:3000
```

Открой этот адрес в браузере телефона. Если не открывается — проверь firewall и настройки изоляции клиентов на роутере.

## Настройки

```bash
SITE_PORT=8080 node server.js     # другой порт (по умолчанию 3000)
HOST=127.0.0.1 node server.js     # только localhost, без доступа из Wi-Fi
npm run dev                       # перезапуск при изменениях (Node 18+)
```

Переменная `PORT` намеренно не используется: в некоторых окружениях она уже занята системным процессом. Для смены порта есть `SITE_PORT` (или `VERITY_PORT`).

Проверка, что сервер жив:

```bash
curl http://localhost:3000/health
```

## Что внутри

```
public/
  index.html            разметка и контент
  css/styles.css        оформление, мобильная вёрстка, анимации
  css/games.css         стили шашек и шахмат
  js/app.js             таймер, смайлик, карточки родни, кликер, генератор мемов
  js/game-engine.js     движки русских шашек и шахмат (без DOM)
  js/games.js           интерфейс игр: доска, режимы, подсказки, AI
  favicon.svg           иконка
  manifest.webmanifest  манифест для установки на телефон
server.js               статический сервер без зависимостей
package.json            скрипты запуска
```

Сервер отдаёт только содержимое `public/`, поэтому `server.js`, `README.md` и `package.json` снаружи недоступны.

## Возможности сайта

- мобильная вёрстка и нижняя навигация;
- таймер «до третьего дня» (хранится в localStorage и перезапускается);
- интерактивный Верити: нажми на смайлик;
- карточки цветных версий: Фолсити, Круэлти, Обисити, Ловити, Куриосити;
- «Верити-кликер» с прогрессией: улыбки за клик, 8 зданий, 10 улучшений, 17 достижений, ранги, золотой Верити, оффлайн-доход и перерождение за печати;
- «Верити-шашки» и «Верити-шахматы»: игра с компьютером или с другом, три уровня сложности, обязательные взятия и дамки в шашках, рокировка, взятие на проходе и превращение в шахматах, отмена хода и переворот доски;
- мем-кухня: выбор смайлика, подпись и скачивание PNG (рисуется на canvas);
- FAQ, таймлайн, анимации появления, поддержка `prefers-reduced-motion`.

## Сервер

`server.js` — небольшой статический сервер на встроенном `node:http`:

- безопасное разрешение путей (защита от `../`);
- MIME-типы, `Last-Modified`, `304 Not Modified`;
- gzip для текстовых файлов;
- заголовки безопасности и CSP;
- `GET /health` → JSON со статусом;
- аккуратное завершение по `Ctrl+C`;
- понятная 404-страница.
